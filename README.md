# DR-SAYANTANI

## WBUHS B.Sc. Nursing (7th Semester) Revision & Study Verification Platform
**Dedicated Study Platform for Sayantani Hauri (সায়ন্তনী বাবু হাউরি)**

---

### 🌐 Deployment
This project is configured for Vercel hosting with a Node server.
- **Main Student Website:** your Vercel production URL after deployment
- **Admin Study Verification Portal:** your Vercel production URL + /admin

If the app shows a Not Found page, redeploy the repo after the latest config update.

---

### 🚀 Key Features

1. **80-Question High-Yield Question Bank** (Midwifery, Child Health, Community Health, Nursing Research & Statistics)
2. **⏱️ 3-Minute Focused Study Timer** with Bengali Voice Encouragement on completion
3. **📸 Instant Attendance & Location Check-In** (auto-captures and closes automatically)
4. **📊 Dedicated Admin Verification Dashboard** tracking attendance photos, live GPS / maps links, and total questions read count
